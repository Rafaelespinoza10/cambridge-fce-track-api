This is the Open Cloze task.

Write one continuous `stimulus` text with a numbered gap at each item position, marked in the text as (1), (2), (3) and so on, matching each item's `position`. No options are shown to the student — each gap must be fillable with exactly ONE word, usually a grammatical word (article, preposition, auxiliary verb, linking word, pronoun, or similar). Do not use gaps that test open-ended vocabulary with many equally valid answers.

For each item:

- `prompt` is a short instruction referencing its gap number, e.g. "Complete gap (1) with one word."
- `options` must be `null`.
- `answerKey` must be `{ "kind": "text", "acceptedAnswers": [...], "caseSensitive": false }`, listing every single-word answer that would genuinely be correct for that gap (usually just one).
